# aside-confirm · DSH 旁路确认插件

[English](./README.en.md) | 中文

在 [DeepSeek Harness](https://github.com/deepseek-ai) 会话里让 agent 开发功能时，如果你没看懂某段 AI 输出，想单独问它一句，又不想打断主对话的连贯——这个插件给你一条「旁路通道」：

- 每条已完成的 AI 回复旁有一个「气泡问号」图标按钮；
- 点击后在右下角打开旁路面板，就这段输出提问；
- AI 结合该消息与最近的会话上下文，在面板里单独回答；
- **问答完全不写入主对话历史**，主 agent 无感知，开发节奏不被破坏。

## 功能

- **旁路提问**：就某条 AI 输出单独提问，回答只显示在面板中，不污染主对话
- **上下文感知**：自动携带「被提问的输出 + 最近 8 条对话」作为上下文
- **Markdown 渲染**：回答支持加粗、行内代码、代码块、列表、标题、引用、链接
- **面板自由**：可拖拽移动、右下角拉伸调整大小、一键重置位置
- **📍 回到原位**：滚动回当初提问的那条消息
- **选中态标识**：被提问的消息图标显示品牌色高亮，关闭面板后恢复
- **多轮问答**：面板内保留问答记录，单行输入框 Enter 发送（输入法组词不误发）
- **中英双语**：界面通过 DSH `locale` 服务自动跟随 DSH 语言设置（中/英），Host 端回答提示词同步切换

## 工作原理

```
┌───────────── DSH 客户端（浏览器）──────────────┐
│ 消息操作行 ──气泡问号按钮──▶ 旁路面板（浮层）   │
│   (conversation.chat.assistant-actions)       │
│                    │  host.call('aside-ask')  │
└────────────────────┼──────────────────────────┘
                     ▼
┌────────────── DSH Host（Node 进程）────────────┐
│ aside-ask 处理器：                            │
│   1. 读取当前默认模型（agentDefaultModel）      │
│   2. 直接调用 llm.stream 发起一次性模型调用     │
│   3. 不经过 agent loop、不产生任何会话事件      │
└───────────────────────────────────────────────┘
```

关键点：回答走 Host 的 `llm` 服务直连模型，**不经过 agent loop、不写会话日志**，所以主 agent 完全不知道这次问答，对话连贯性零破坏。

## 安装（DSH 动态插件）

本插件是 DeepSeek Harness 的**动态 Cordis 插件**：进程内的临时扩展，不修改 DSH 源码、不需要重新构建。

把本仓库交给你的 DSH 会话（或把文件内容发给它），让它：

1. 用 `cordis_define` 创建插件：`plugin.kind: "new"`、`idPrefix: "aside"`，`code.host` 填入 `src/host.js` 的内容，`code.client` 填入 `src/client.js` 的内容；
2. 用 `cordis_run` 激活（首次会弹出授权请求，勾选允许即可；双勾选可让该插件未来版本自动通过）；
3. 激活完成后，每条已完成的 AI 回复旁会出现「气泡问号」按钮。

### 更新

代码改动后，在同一个 `pluginId` 上用 `cordis_define`（`kind: "existing"`）追加新版本 Package，再用 `cordis_run`（`mode: "update"`）切换版本；新版本失败时可用旧版本回滚（`mode: "run"`）。

### 注意

- 动态插件只存在于当前 DSH 进程：DSH 重启后需要重新定义并激活；
- 回答使用会话当前选中的默认模型；
- 界面语言自动跟随 DSH 语言设置（内置中英文词典）。

## 使用

1. 鼠标悬停到没看懂的那条 AI 回复，点击操作行里的气泡问号图标；
2. 在右下角面板输入问题（例如「这段为什么这样实现？」），Enter 发送；
3. 面板中查看 Markdown 回答，可连续追问；点 📍 回到那条消息；
4. 关闭面板（✕）后继续原来的开发节奏。
